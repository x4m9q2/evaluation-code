This code repository includes only small metadata/configuration files. Large
image corpora, upstream benchmark files, and released dataset artifacts should
be downloaded separately and placed under the relative paths documented in
`README.md` and `docs/LLAVA_SAGE_REPRO.md`.

The public dataset release is hosted separately. A copy of its README,
manifest, and Croissant metadata is kept under `data/sage_as/` for reference.
